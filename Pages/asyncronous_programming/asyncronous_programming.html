Asynchronous Programming

Asynchronous programming is a paradigm (a style of programming) that allows a program to start a long-running task and still be able to respond to other events while that task runs in the background. The opposite of asynchronous is synchronous programming, where tasks are executed one after the other, and a task must complete before the next one can begin.

Asynchronous code is non-blocking. It tells the program to start this long-running task now, without waiting for it. That it should move on to the next instruction in the code. Now, when the task is finally finished, the code should be prepared to handle the result.

The Core Reason

The primary environment for TypeScript, the browser, uses a single-threaded architecture for executing TypeScript code. This single thread is often called the "main thread".

If a task that takes a long time is executed synchronously, the single thread gets blocked during that task's execution. While the thread is blocked, the browser becomes unresponsive. The user can't click buttons, animations freeze, and the user experience is ruined.

Core Concepts

'Promise' Concept

A Promise is an object that represents the eventual completion or failure of an asynchronous operation and its resulting value.

This Promise doesn't contain the final data yet; it simply promises that it will produce a result, or an error, sometime in the future. The Promise object acts as a placeholder for the result, allowing the synchronous code to keep running while the background work finishes.

It has two key methods: then and catch. The then method is used to handle the resolved value, while the catch method is used to handle any errors that may occur during the asynchronous operation.

General Promise Syntax

promise
  .then((data) => {
    console.log("SUCCESS:", data);
    return "Processed " + data;
  })
  .catch((error) => {
    console.error("ERROR:", error.message);
  });

'Async' Keyword

It declares any function as asynchronous

It must be placed immediately before the function keyword, before the parameter list for an arrow function, or within an object method definition.

Function Type Syntax
Declaration async function myFunc() { ... }
Expression let myFunc = async function() { ... }
Arrow Function const myFunc = async () => { ... }
Object Method const obj = { async myFunc() { ... } }

'Await' Operator

Gives the async function its non-blocking power. It can only be used inside an async function.

It is placed immediately before a Promise.

It tells the TypeScript runtime to pause the execution of the surrounding async function until the Promise settles (either resolves or rejects). If the Promise resolves, await returns the resolved value. If the Promise rejects, await throws an error, which can be caught using a standard try-catch block.

Async Functions in TypeScript

The general structure is the following:

async function functionName(param1, param2) {
    const result1 = await somePromiseReturningFunction();
    console.log('Result 1 is ready. The next line will pause.');
    const finalResult = await anotherAsyncOperation(result1);
    return finalResult;
}

Example: Async Function

Run the function printAsyncMessages and look the order of the messages.

async function printAsyncMessages() {
    const delayMessage = (message: string, ms: number): Promise<string> =>
        new Promise(resolve => setTimeout(() => resolve(message), ms));

    const p1 = delayMessage("Message 1 (300ms delay)", 300);
    const p2 = delayMessage("Message 2 (500ms delay)", 500);
    const p3 = delayMessage("Message 3 (200ms delay)", 200);

    console.log("Starting...\n");

    await Promise.all([
        p1.then(v => console.log(v)),
        p2.then(v => console.log(v)),
        p3.then(v => console.log(v)),
    ]);
}
