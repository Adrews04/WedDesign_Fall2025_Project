Basic Types

This section we will go in depth on the basic types in programming languages as well as how to apply them.

Basic types typically found within TypeScript

Basic Types Description Written Examples (variable declarations)
number refers to integers let age: number = 27;
string refers to any characters let name: string = "Hello World!";
boolean true or false values let isUserOnline: boolean = false;
null equal an empty value let totalCurrentClasses: null = null;
undefined not clear or defined let result: undefined;
any holds any value and reassigned a different value later let givenInput: any = 00;
void absence of a value function giveReport(): void { ... };

Overview of Static Types

Static Types Description Written Examples (variable declarations)
Annotation assigning a type to variables, parameters, or return values let numVariable: number = 29;
Nullable These are special case of union types that allow null or undefined value types let email: string | null = null;
Union Allowing a variable to be one of multiple types using " | " let id: number | string;
Unknown Safe alternative to the any keyword. Values of type unknown must be type-checked before being used or modified let givenData: unknown;
