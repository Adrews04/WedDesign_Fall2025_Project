Functions

Basic Function Components

In this section, we will go over how functions are formed and how they operate, showing the different components that make up a basic function.

Terms Description Possible Code Examples
function used to declare a basic function with the function keyword. function greet(name: string): string { ... }
parameter variables listed in a function definition that receive values when the function is called. function greet(name: string): string { ... }
function body refers to code written within a function used to complete tasks when called upon. The function body is always wrapped with braces { }. function greet(name: string): string { ... }
function calling the act of executing a function by referencing its name and supplying arguments, if required greet("Emma");
function return once the function finishes executing, the return keyword sends a value back to where the function was called. function greet(name: string): string { return `Hello ${name}!`;}

Return Types

In this section, we will understand how TypeScript allows us to define the return value type of a function.
The highlighted section below refers to the type of return value the function will eventually return. 

function greet(name: string): string {
    return `Hello ${name}!`;
}

Other return values that have the ability to replace the keyword string in : string

Return Type Description Use Cases
number returns a numeric value function addTwo(value: number): number { ... }
boolean returns either true or false function isGreeting(action: string): boolean { ... }
null indicates the absence of a value function greet(name: string): string | null { ... }
undefined indicates no value and is rarely used as a return type function greet(name: string): string | undefined { ... }
any disables TypeScript's type checking; use with caution function getStoredValue(): any { ... }
void returns no value function giveStatusUpdate(message: string): void { ... }
